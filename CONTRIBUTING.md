# Contributing to terminfo.dev

Thank you for your interest! Ideas, bug reports and questions are very welcome; please open an issue. A clear description, or a small example that shows the problem, helps most, and we aim to answer quickly.

This repo accepts direct pull requests from long-term collaborators only. For everyone else, we write each change ourselves from your description, and we credit you by name in the release notes. With AI-assisted development, building each change ourselves from a clear description is the safer and faster path for everyone.

Please describe the problem rather than pasting large pieces of code; short snippets that reproduce a bug are fine.

## Submitting probe results

The corrected CLI is being prepared for release; see [the contribution guide](docs/contribute.md) for its current status and verified collection instructions. Its `submit <run.json> --draft <draft.md>` command prepares a draft and an exact copy of the run locally. Review both before posting a GitHub issue.

If you choose to contribute results, include this statement in your issue:

> I dedicate these results to the public domain (CC0 1.0) so terminfo.dev can publish them under any license.

Creating a local draft does not submit the results or grant consent. Accepted contributions are credited on the terminal's page.
